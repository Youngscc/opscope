# 算子性能实验室 · PC 交互原型

直接用浏览器打开 `index.html`。单文件内嵌样式、脚本与结果包，无 CDN 或运行依赖。

主要交互：硬件/方法筛选；同硬件比方法、同方法比硬件；点击摘要打开详情；勾选两个结果并排比较；五个详情页签；导出 JSON 预览、文本选择和下载链接。默认 PC 布局，窄屏可在表格内横向滚动。

所有性能数值、计数器与流水事件均是合成演示数据。固定 MatMul 4096³ / FP16 输入，不运行真实评估器，不代表方法支持或精度验证。原型仍未接入业务路由、后端或真机。Roofline 合并后，覆盖 Ascend 9382、H100、H200、B200、B300 共 17 个有数据的硬件/方法组合；R200 和不支持或待确认的仿真组合显示缺失原因。

## 重新生成

```bash
python3 -B build.py
python3 -B -m unittest discover -s . -p 'test_*.py' -v
node --check app.js
```

Python 完成数值和图形数据预处理，JS 只处理展示与选择。若后续接入 Vue，保持计算在后端，并用正式结果 ID/来源/边界/版本替换私有示例结构。

## 外层可视化更新

外层新增有效算力条形图、HBM 实际流量/平均带宽、L2 命中率进度条和 Cube/Vector 或 Tensor/SIMT 活动条。有效算力按逻辑 FLOPs/总时延折算，所有方法共用 2400 TFLOP/s 图形尺度，不是峰值利用率；资源比例按各硬件原生口径展示。模型未提供的实际访存/资源指标保留缺失。固定合成计数器由同一 fixture 生成内外层。

更新后 5 项测试通过，新增核对算力换算、带宽单位、图形比例、内外层一致性与缺失语义。PC 浏览器验证新增访存/活动图直接打开对应详情、两种比较视角正常，无脚本错误。重复实验分布仍已移除。

## 排版打磨

详情指标使用紧凑分组，标签在数值上方；总时延突出显示。执行依据和参数对话框使用固定标签列、左对齐数值，避免横跨整屏。单结果选择器限制宽度，单结果去掉重复标题；双结果选择器和指标网格等宽对齐。资源名称和百分比就近排列，外层微图限制最大宽度，统一表头字号、卡片间距和空态高度。

已在 PC 浏览器目视检查耗时、访存和双结果计算页；重复实验分布仍不展示。此轮不改性能数值、结果来源、筛选和比较行为。Skill 定向检索未命中空间邻近规则；布局调整依据一般信息分组原则及实际截图，不将无关检索结果作为设计证据。

## 示例数据补全

此节为合并前的验证记录；当前方法与覆盖数见后文“Roofline 合并”。

新增 `execution_data.py`，集中生成各硬件/方法的执行示例；外层摘要、详情和导出记录使用同一数据源。补齐计算/访存活动时间、等待时间、HBM 流量/带宽、L2 命中率、计算资源活动、Tiling、缓冲级数、局部流水和核间活动。

Roofline 仅提供解析成本与校准参数，不生成 kernel 或指令事件。Tilesim 新增细项标为“扩展字段示例”，当前适配器尚未提供这些输出。详细示例展示 24 个活动实例和 12 个局部 tile 事件，不代表实际核数或完整 trace。所有时钟、内核名称、配置与性能值均为虚构演示。

更新后 7 项定向测试通过，覆盖 22 组数据、事件边界、周期换算、内外层一致性、解析模型字段边界和缺失语义；JS 语法检查通过。PC 浏览器核对 Tilesim 流水、B200/B300 外层结果、执行依据、Roofline 成本详情和跨硬件视角，无脚本错误。

## Roofline 合并（2026-09-21）

筛选和对比表仅保留一个 Roofline 方法。Ascend/H100/H200 分别演示分桶、聚合、回归校准，B200/B300 演示通用估算；状态标签不代表真实校准库命中。校准来源、虚构版本、匹配条件和参数放入执行依据，回归结果的计算/访存与瓶颈为缺失值。导出同样保留来源元数据与 null，删除独立 calibrated 结果。

8 项定向测试、JS 语法检查通过。PC 浏览器已检查两种比较视角、双结果详情、两类状态标签以及 JSON 的四类来源和缺失值，无脚本错误。Skill 定向检索未找到适用的信息披露规则，沿用用户确认的 PC 信息分层与现有交互。
