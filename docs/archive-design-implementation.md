## 边界与验收

逐图核对布局及可达交互，桌面1920与1280检查溢出；验证配置取消/应用、筛选确认/重置、两条比较、JSON、三个工作台。数值和图宽仍由Python准备。保留 synthetic 标记、GPU/NPU区分、Roofline无流水、已确认的Fixpipe和执行流水名称、默认展开的输出张量表。设计截图中重复值和错位单位不作为新数据来源。

图中新增 RMSNorm/asfdevg 已由用户确认为占位，不作为默认族。其他18张图均已找到现有页面/交互落点。

## 算子族补充需求

用户确认 RMSNorm/asfdevg 是占位，改为支持 JSON 配置族。`family-import.ts` 验证文件、构造会话目录、选择已有结果；MegaKernel 提供导入、模板下载、状态与待接入列表。语义与示例见[导入说明](family-json-import.md)。继承原始 Python 排名和 pair，不重算性能。默认输出张量仍展开；参考中旧的“查看优化方向”重复跳转不恢复。

## 验收结果

18项映射全部有对应实现并在浏览器走查：主页面及展开表格、平台/方法确认与重置、类别多选、族搜索、五个详情页签和JSON弹窗。1920与1280桌面无页面横向溢出，矩阵在窄桌面内滚动。额外验证输出形状联动/取消、尺寸非法输入、两条结果synthetic导出、复制、流水缩放/空闲显隐、有效及错误JSON保留原目录。源码构建与两种单文件均成功；HTTP预览验证，file协议未实测。未恢复用户此前已删除的重复跳转按钮，未替换已确认的技术名称或抄入设计图占位数据。
