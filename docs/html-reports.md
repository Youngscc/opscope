# 独立 HTML 报告

> 当前界面直接从矩阵选择两个结果，见[矩阵双结果比较](matrix-comparison.md)。历史评估接口保留兼容，时间选择区已移除。


## 目标与来源边界

参考 modeling 的 `backend/train/zrt/training/io/comparison_report.py` 与 `backend/train/zrt/report/html_writer.py`：报告为可下载的独立 HTML，先给结论，再给图表、输入依据和细节。OpScope 不具备模型级归因、敏感性重跑或实测校准，不能把 modeling 的相应章节照搬。报告生成只依赖本仓库保留的评估快照，不调用 modeling，也不重新执行模拟。

## 两类报告

- **两次评估对比报告**：从历史对比页已选的 A/B 时间生成。沿用 `/evaluations/compare` 的同一配对和可比性判定，包含任务身份与时间、同口径数量/方向计数、统一刻度成对耗时图、各组合的原值/缺失原因，以及每一组合按章节对齐的字段。不同配置、规格或引擎身份时只列两侧结果，不写加速比或胜负结论。
- **单项与事件详细报告**：从实际评估结果详情下载。包含本次结果的算子/输入、硬件、方法/引擎身份、全部结构化章节、原始预测字段及状态。TileSim 有事件时展示各核/通道活动摘要、时间轴和完整事件明细；无事件时说明上游模型没有提供流水。事件时间单位为 μs，活动区间可重叠，不能相加为总耗时。

HTML 内联样式与数据，无外链资源。文本全部 HTML 转义，不直接注入 `details` 的 HTML 片段；事件大列表分页显示，但完整事件数据保留在文件内。报告不含源仓库路径、凭据或任意文件读取。下载接口只接受运行时保留的终态任务与其中的结果标识；任务被淘汰或重启后接口返回 404。原有完整快照导出仍保留，语义不同于报告。

## 验收

- 页面能下载 A/B 对比报告和单个结果报告，离线打开无网络请求。
- 报告与在线结果数值、可比性和缺失原因一致，A=0 时不出现除零比例。
- 有事件时保留全量事件、核/通道/类型/开始/时长；无事件时不造流水。
- 不可比结果不进入胜负计数；动态字符串不能逃逸 HTML/脚本数据块。
