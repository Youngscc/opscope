# 实现与开销对比

MegaKernel原实现结构卡改为“实现与开销对比”。保留基线/当前执行链和Kernel启动次数；直接展示总耗时、相对基线加速比、节省时间、峰值设备内存、中间结果峰值、临时工作区和累计读写量，不再重复UB利用率。采用基线/当前两列，空间指标以MiB统一显示，支持当前既有基线、成员、范围、规模和硬件切换。

空间数据为人工展示预设，存放在Python中，不从UB利用率或读写量倒推。memory字段包括input_output_mib、intermediate_mib、workspace_mib、peak_mib及synthetic。峰值仅在本预设约定输入输出、中间结果及工作区同时驻留时求和；中间结果与工作区互斥分类，不代表真实运行的存储分配策略。Attention小规模输入输出按S线性缩放、中间矩阵按S平方缩放；这些仅用于样例一致性，不新增性能估算能力。

Python预处理展示字符串，Vue展示和切换，缺失通过—表示、零值保留；JSON带原始空间值和synthetic。真实来源缺少空间数据时不得套用本预设。测试具体MatMul/融合/Attention数值、峰值求和、小规模及零中间结果；浏览器验证切换和基线自比。两类单文件与在线组件同步。
