# 三页输入侧栏

将原横排配置改为标题下的左右布局，参考 modeling 性能实验预览的侧栏组织。保留当前蓝灰主题，三页共用280px输入列、24px间隔和可收缩结果列；宽桌面内容区上限1760px。小桌面侧栏256px，矩阵在结果卡内部滚动，窄屏再堆叠。

评估左栏包含算子、所有张量形状、平台/方法筛选及执行/导出入口；右栏包含矩阵与两张柱图。分析左栏包含算子、平台、尺寸、自定义及导出，右栏包含诊断、资源、流水和建议。MegaKernel左栏包含族、范围、平台、尺寸、基线与导出，右栏保留排名、当前成员、指标、实现结构与趋势。

复用原选择状态、弹窗、详情和导出，不改变Python计算、数据契约、示例标记与缺失语义。ResultMatrix通过results插槽接入柱图，使两者共用右列；其余两页用同一布局类。验证三页桌面布局、选择、详情与比较、JSON及构建；同步两个Vue单文件，原生旧矩阵不改布局。

左侧白色输入栏与右侧完整结果区等高，配置项顶对齐，剩余区域保持白色留白。窄屏堆叠时按内容自然高度。
