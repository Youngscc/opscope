# MatMul计算类型与独立尺寸

MatMul族增加普通矩阵乘、批量矩阵乘、共享权重矩阵乘、Linear+GELU计算类型。M/N/K独立选择1024或4096；批量与共享权重支持Batch=1或4，普通与融合固定Batch=1。使用有限预设可确保所有可选组合都有合成数据，不在浏览器估算任意输入。Attention沿用原有尺寸配置。

Python构建独立尺寸样例，以既有时延为合成种子按演示比例缩放，重新生成排序、比较、内存和资源展示；不表示性能预测。记录完整类型、B/M/N/K、输入张量形状和synthetic，JSON保持这些身份。尺寸趋势固定当前Batch/N/K，仅改变M，轴标签明确固定条件。BMM的B输入带Batch，共享权重的权重不带Batch，候选成员沿用实现策略名称，新增类型没有额外宣称真实kernel支持。

诊断MatMul写回通道标为Fixpipe（L0C→GM）；Attention原示意另行保留，不做全局MTE3替换。测试形状身份、结果切换、内存和比较一致性及全部组合覆盖。

## 并列算子族

界面现在直接列出MatMul、BatchMatMul、共享权重矩阵乘、Linear+GELU、Attention五族，不再展示计算类型或对比范围控件。workspace_families为扁平展示目录，每族仅一个内部范围；维度结果family_id和member_id同步对应独立族。原families保留为构建模板，不用于新界面族选择。

前三族采用不同实现策略名称及独立的硬件时延/流量示例种子：MatMul为分块流水，BMM为批次调度，共享权重为权重复用。Python先特化种子再生成维度组合，成员名、执行链和趋势同步。它们仍为人工示例，不声明真实kernel支持。
