# 矩阵内选择两个结果

用户从当前硬件×方法矩阵选择两个结果，不再先选择评估时间。每个有结果的卡片常驻“加入对比”；选中后标记 A/B，矩阵上方展示对象名称、清空和“对比所选”。最多两项，可取消并换选；筛选隐藏的项自动移除。卡片主体继续打开单项详情。

比较在现有浮窗完成：同尺度总耗时条形图、原有分类指标并排展示、仅看差异、JSON，以及独立 HTML 对比报告。未满足原有可比条件时仍显示原始数值，保留原因，不生成误导性的变化率。Python 预处理图宽和变化率，Vue/离线 JS 只展示。

在线页面移除评估时间区；已有历史查询接口保留兼容。新增按当前任务结果 ID 下载报告的接口，示例数据用 bootstrap；运行中只允许选择已完成的卡片，未知任务不回退示例。离线页面同步直接选择交互和耗时图，报告下载由在线接口提供。

验证：矩阵数据和报告接口回归、前端构建、离线构建与脚本检查，桌面实际点选/取消/第三项限制/筛选/详情/JSON与报告。
