# 优化工作台界面

## 范围与入口

在 Vue 前端新增 `/optimization`（算子性能优化）和 `/megakernel`（MegaKernel 优化），与原性能矩阵并列导航。两页独立读取构建期示例，不提交评估、不读取矩阵结果，也不改变现有服务契约。此轮不实现诊断算法、搜索算法、真机采集或候选编译。

页面使用同一浅色背景、蓝色操作、深色数字和细边框。领域对象为工作负载、计算/搬运/等待、核流水、最终诊断、实现与融合边界。暖色只强调瓶颈，青色表示改善，紫色标识 Vector 流水。统一诊断与关键流水区间构成诊断页重点；同尺度排名与融合算子链构成 MegaKernel 页重点。保持现有系统字体，以等宽数字区别性能值；页面间距24px、面板24px、控制项12px。避免均匀的 KPI 卡片网格、装饰渐变与长段说明。

设计检索中的横向比较图建议适用；自动设计系统推荐的营销页结构不适用，因此布局和色彩以现有项目为准，不引入字体/CDN/图表依赖。

## 页面与交互

- 性能优化：算子、硬件与 Size 选择，支持弹窗编辑各维度；展示单一任务耗时、最终瓶颈结论、资源压力、静态关键流水与瓶颈区间、按优先级展开的建议。
- MegaKernel：先选择人工定义的算子族，再查看族内成员；支持对比范围、输入规模、基线和指标切换，展示成员排名、选中成员细节、融合边界和规模趋势图。
- 两页只向用户公开最终结果，不出现方法名称、方法数量、来源标签或方法切换；图表解释瓶颈与实现差异，不用于比较评估方法。此规则覆盖页面、提示、选择上下文和JSON导出。不同 kernel 实现仍是 MegaKernel 的比较对象。
- `MatMul` 只比较 `A×B`（Linear 关闭 bias）；`Linear + GELU` 单独比较 `GELU(XW+b)` 的分算子和融合实现。不能跨语义计算比值。
- 顶栏始终显示“示例数据”，导出 JSON 保留全局与每个预设的 `synthetic: true`、选择上下文。页面不使用虚假运行按钮。

## 人工定义的族（2026-10-08）

族是独立的人工配置对象，名称和成员归属不根据算子名称或结果自动推断。示例包含 MatMul 和 Attention 两个族；同一族可包含算子、融合算子，以及用于比较的分算子组合。页面以“算子族 → 族内成员”为主层级：上方选择族，成员列表直接标记类型，右侧展示最终收益。继续采用现有冷灰背景、蓝色选中态、浅边框和等宽性能数字；族选择不另建复杂管理表格。

族的归属不等同于计算语义等价。MatMul 族同时含矩阵乘与 Linear + GELU，使用简短的“对比范围”切换，分别计算排名和比值；Attention 族以标准非因果、无 dropout Attention 为示例，完整任务包括分算子或融合执行。切换族一次性重置范围、规模、基线与当前成员，不携带上一族的选择。当前仅预设展示，不新增族的在线增删或持久化管理。

实现顺序：先扩展 Python 族定义、显式成员类型和比较范围，生成展示资产；再让 Vue 从配置渲染族选择、类型标签与形状/趋势轴；最后核对族归属、跨范围隔离、选择重置、基线自比和 JSON 上下文。缺少可比结果不能靠同族身份补造比值。

## 模块与数据

### 可选择与编辑的 Size（2026-10-09）

诊断配置区以三个明显的选择项呈现算子、硬件、输入 Size，沿用性能矩阵的蓝色边框/浅蓝背景与主操作按钮。每个算子提供三组尺寸预设，另用“配置输入”打开现有 Modal 基础组件，编辑 MatMul 的 M/N/K 或 Attention 的 B/H/S/D；保留固定精度显示，不接入实际计算。弹窗先编辑草稿，应用后更新页面，取消或 Escape 不提交。

结果按算子、硬件与完整尺寸精确匹配；切换算子加载其默认尺寸，保留硬件，切换硬件保留尺寸。自定义尺寸必须为正整数；合法但没有预设的尺寸显示空结果、禁用导出，不缩放或借用其他尺寸的诊断。三组尺寸的耗时与指标由 Python 显式预设，输入张量元数据与图表也在 Python 生成。展示资产升级v5，JSON记录所选尺寸、维度和输入张量。先扩展尺寸目录和预设，再实现快捷选择与草稿弹窗，最后验证尺寸切换、应用/取消、校验、空状态和导出。

### 诊断结果与预设

MatMul/Attention × Ascend 910B1/910B4 × 各三组尺寸，共12组展示结果。MatMul 预设 M=N=K 为1024/2048/4096，默认4096；Attention 预设 B=1、H=32、D=128，S为512/2048/4096，默认2048。四个算子/硬件组合分别定义结论与建议，各尺寸的耗时和资源压力显式预设，不根据维度外推。局部流水的重点区间由 Python 根据对应窗口预处理，可指计算密集或等待片段。

目录只服务示例展示，不扩大后端硬件支持范围。没有精确组合时保留全部选择，展示空结果并禁用诊断导出，不能回退到其他组合。JSON 包含算子、硬件、尺寸身份、完整维度和对应结果，保留 synthetic。

`opscope/offline/optimization_demo.py` 定义预设并计算比值、图宽、坐标与标尺；`build.py` 同步生成 `frontend/src/data/optimization-demo.json`。这些是展示 fixture，不是性能算法。Vue 页面负责选择/筛选/展开，通用组件绘制流水与趋势，独立 CSS 复用根设计 token。原 `demo.html` / `index.html` 的矩阵导出链路保持独立。

`opscope-optimization-demo-v5` 只包含人工配置与结果层数据；`diagnostic_catalog` 定义诊断算子、硬件、维度轴、默认尺寸和输入张量，`diagnostics` 按 `operator_id + hardware_id + dimensions` 精确提供结果。`families` 显式记录族身份、成员身份/类型及比较范围，`mega` 按 `family_id + scope_id + size` 提供结果。成员使用范围内唯一的 `member_id` 与族目录关联；导出包含当前结果和完整选择上下文，MegaKernel 另保留选中的族定义。预设诊断与单一耗时由人工定义，不对多方法结果平均或计算融合。各通道活动可以重叠，不当作时延可加拆分。局部流水明确是示意窗口，不冒充全核 trace。基线比值只在同一任务、精度、规模、硬件和计时边界内生成。

## 验收

1. 两个路由直接访问、顶栏切换、浏览器返回均可用；独立于后端服务。
2. 更换预设同步更新结论、图表和详情；诊断切换算子保留硬件并重置尺寸，切换硬件保留算子和尺寸；输入草稿仅在应用时生效，取消/Escape保持原配置，非法维度阻止提交，无对应尺寸返回null；切换 MegaKernel 族、对比范围或规模重置当前基线与成员，避免旧数据残留；重复点击当前族保留选择。
3. Python 测试验证族与成员归属/类型、具体比值、方法信息不外露、坐标边界、语义隔离、synthetic 与构建产物一致；Vue 类型检查和生产构建通过。
4. 桌面检查导航、筛选、细节、基线比较、JSON；窄屏检查无溢出，支持键盘和减少动态效果。返回桌面视口后交付。
5. 不修改当前矩阵的公式、方法、硬件身份及真实评估逻辑。不自动部署到宿主 zrt-sim。
