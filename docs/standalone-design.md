# 独立项目打包设计

日期：2026-09-21

## 目标与边界
将 modeling 内的单算子前端原型复制为独立、可移动的项目，保留现有功能和数据。交付完整源码目录及 ZIP。原 modeling 副本保留，不修改业务后端或正式前端。

## 结构与依赖
保留根目录同级 Python 生成器、fixtures、HTML/CSS/JS 和测试，避免引入构建框架。Python 仅依赖标准库，浏览器离线可运行。新增 README、AGENTS.md、.agent/MEMORY.md、数据语义与接入说明、架构说明、历史记录和忽略规则。所有内部文档引用使用相对路径。

## 验收
在独立目录运行生成和测试，确认生成 HTML 与原版逐字节一致；ZIP 解压到另一目录后重跑同样检查。原样提取以生成页面逐字节一致和独立 HTTP 访问验证，沿用原版 PC 浏览器验证记录。压缩包带 SHA256SUMS，不包含原仓库数据库、凭据、Git 历史或无关文件。
