# 三页单文件静态演示

需要交给设计师直接修改布局时使用 [opscope-ui-design.html](../opscope-ui-design.html)，其中模板、CSS、JSON均可读且可独立编辑；流程见[UI设计交接](ui-design-handoff.md)。本说明继续维护展示版opscope-demo.html的生成与数据规则。

## 目标与实现

当前单文件 demo.html 仅覆盖旧矩阵，Vue 矩阵依赖服务。新增 opscope-demo.html，复用当前 Vue 三个页面，通过独立 demo 构建模式嵌入全部 JS、CSS 和预设数据，以 hash 路由支持直接 file:// 打开和页面切换。原在线构建与旧离线导出保留。

Python 从现有矩阵预设中提取五种已有完整结果的示例硬件、五种方法和默认 MatMul 4096³ FP16 配置，共25条；在该集合上重新生成图表及双结果比较。演示矩阵保留算子选择与输入配置，不展示后端运行或服务报告入口，保留筛选、详情、双结果对照及 JSON。优化与 MegaKernel 使用现有各12组预设和全部选择交互。

数据始终标记 synthetic；不把未知型号补成支持，不为缺失分项造计数器或流水。自定义诊断尺寸仍严格匹配，未预设的尺寸显示空状态。静态模式在 store 和 API 边界禁止请求，不启动真实评估。用构建期常量和虚拟模块隔离在线模式，数值与图表仍由 Python 生成。

## 算子选择与输入配置（2026-10-13）

恢复标题中的“选择算子”入口，复用在线页的 OperatorConfig 弹窗及搜索、类别、输入形状、精度、属性和应用/取消交互。Python 保留完整算子目录及五种示例硬件对应的25条空结果模板；JS 复用现有配置精确匹配，不根据尺寸推导性能。默认 MatMul 配置展示原25条结果，其他配置显示“未预设该配置的示例结果”，结果数值与执行信息保持为空。载入 MatMul 示例后恢复原数值与详情。

应用配置清空已选对比和图表聚焦，导出使用当前输入及对应结果；全局示例标记持续显示。静态弹窗使用“预设数据展示”文案，不引导运行评估。运行与 API 保护继续保留，在线模式沿用原流程。

配置错误链接直接聚焦输入并滚动至可见位置，保留当前 hash 路由；取消或 Escape 不提交草稿，并将焦点返回选择按钮。

实施顺序：保留目录和空结果模板，再恢复按钮、静态配置应用及文案，最后重新生成单文件。验收覆盖默认25条结果、搜索并应用 Mul、修改尺寸后的空结果与 JSON 一致性、取消/Escape、恢复示例、矩阵筛选/详情/双比较及三页导航。

## 验收

- 生成单个无外部资源依赖的 HTML；不依赖 CDN、服务端或相邻文件。
- 三页切换、刷新、矩阵筛选/详情/双比较/JSON、诊断及 MegaKernel 配置可用。
- 25条矩阵结果全部可用且 synthetic，关键数值、图表及比较保持现有口径。
- 在线类型检查/生产构建和现有测试通过；浏览器确认桌面展示及无 API 请求。

生成：先运行 `python3 -B build.py`，再运行 `npm --prefix frontend run build:demo`。产物位于仓库根目录 opscope-demo.html，原 demo.html 继续作为矩阵旧版。
