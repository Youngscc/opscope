# 三页单文件静态演示

## 目标与实现

当前单文件 demo.html 仅覆盖旧矩阵，Vue 矩阵依赖服务。新增 opscope-demo.html，复用当前 Vue 三个页面，通过独立 demo 构建模式嵌入全部 JS、CSS 和预设数据，以 hash 路由支持直接 file:// 打开和页面切换。原在线构建与旧离线导出保留。

Python 从现有矩阵预设中提取五种已有完整结果的示例硬件、五种方法和固定 MatMul 4096³ FP16 配置，共25条；在该集合上重新生成图表及双结果比较。演示矩阵固定输入，不展示后端运行或服务报告入口，保留筛选、详情、双结果对照及 JSON。优化与 MegaKernel 使用现有各12组预设和全部选择交互。

数据始终标记 synthetic；不把未知型号补成支持，不为缺失分项造计数器或流水。自定义诊断尺寸仍严格匹配，未预设的尺寸显示空状态。静态模式在 store 和 API 边界禁止请求，不启动真实评估。用构建期常量和虚拟模块隔离在线模式，数值与图表仍由 Python 生成。

## 验收

- 生成单个无外部资源依赖的 HTML；不依赖 CDN、服务端或相邻文件。
- 三页切换、刷新、矩阵筛选/详情/双比较/JSON、诊断及 MegaKernel 配置可用。
- 25条矩阵结果全部可用且 synthetic，关键数值、图表及比较保持现有口径。
- 在线类型检查/生产构建和现有测试通过；浏览器确认桌面展示及无 API 请求。

生成：先运行 `python3 -B build.py`，再运行 `npm --prefix frontend run build:demo`。产物位于仓库根目录 opscope-demo.html，原 demo.html 继续作为矩阵旧版。

## 已验证与限制

28项Python定向测试、11项前端测试、Vue类型检查、在线及单文件构建通过。HTML仅含一个内联普通脚本，无外部样式/脚本；脚本语法检查通过，CSP禁止连接。浏览器通过只提供该HTML的本地HTTP服务检查25/25矩阵、硬件筛选至20/20再重置、单项/双项详情、流水、JSON下载、三页导航和刷新、键盘跳过导航；诊断Attention/910B4/S512为63.2μs，融合比较910B4为84.6μs、1.91×。1280px桌面无页面横向溢出。

内置浏览器不允许file协议，直接双击的file://路径未实测；HTML按无模块加载、无外部资源的离线形式构建。首次预览发现库构建保留process环境引用，已通过生产环境常量修复，后续页面切换无新增控制台错误。此次未运行实际评估或推送部署。
