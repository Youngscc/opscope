# UI 设计交接单文件

## 目标与方案

将当前三个工作台和弹窗交给设计师修改，提供独立的 `opscope-ui-design.html`。单文件内包含可读的页面/组件模板、样式、示例JSON及运行脚本，修改模板或样式后刷新即可预览；无需安装依赖、启动计算后端或读取相邻文件。

复用当前 Vue 组件的 script setup、Pinia、路由与配置逻辑，构建时保留组件模板为 `text/x-template` 区块，使用 Vue 自带的模板编译器在浏览器中渲染。每块模板记录对应源文件；样式保留可读格式，两份示例JSON独立放在 `application/json` 区块。模板编译只服务可信的本地设计稿，交接页允许内联脚本及模板编译，保持 `connect-src 'none'`，不请求接口。

构建脚本使用既有Vue/Vite工具，不安装新依赖。模板中的TypeScript类型断言转换为浏览器JavaScript；setup返回值通过普通实例代理访问，导入的Vue组件显式注册，保留现有事件、props和slot行为。内嵌运行库保持可读，当前共19块组件模板。

默认矩阵展示原25条MatMul合成结果；完整算子目录、输入配置、筛选、详情、双结果比较、JSON，以及性能优化/MegaKernel的所有现有选择交互继续保留。未预设配置仍为空，不新增性能公式或硬件支持。保留全局示例标记及synthetic。

矩阵下方现为两张总耗时柱状图：选择平台比较不同方法，选择方法比较不同平台。两图共用零起点刻度，支持独立选择、矩阵行列联动与柱条详情；参考偏差仍保留在矩阵。该布局已同步到可编辑的 ComparisonChart 模板和原始样式区。

## 设计师编辑与回传

1. 修改 `designer-styles` 中的样式，及标注 `data-source` 的页面/组件模板；数据区可用于调整展示内容。
2. 保持数据字段、模板绑定与事件含义，便于保留筛选、选择和导出行为。直接刷新查看三页和弹窗。
3. 回传修改后的整个HTML，先保留回传稿并读取差异，完成迁回后再重新生成交接文件。按模板的源文件映射迁回Vue组件，并将样式合入现有样式文件；核对当前结果和交互契约后，通过数据适配层恢复接口读取。设计稿用于确定布局和交互，在线版继续沿用现有服务流程。

## 实施与验收

新增专用构建脚本与 `npm --prefix frontend run build:design`。先由 `python3 -B build.py` 更新示例资产，再构建交接文件；原在线和展示版构建保留。

检查单文件无外部资源、示例JSON与现有资产一致、三个页面及所有组件模板完整。浏览器检查三页、输入/硬件/规模选择、详情/对照、JSON与桌面布局；额外通过修改交接HTML中的标题和CSS，验证刷新后编辑生效。内置浏览器不能直接访问file协议时，用仅含交接文件的本机HTTP预览，明确保留file协议未实测状态。
